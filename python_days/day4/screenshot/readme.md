
Project Description
This project focuses on cleaning and analyzing a weather dataset using Python and Pandas. The dataset is stored in an Excel file called rowsdate.xlsx.

The main goal of this project is to identify missing values, calculate the mode of each column, and determine how frequently the most common value appears.

Dataset
The dataset contains the following columns:

Weather_Date – Date of the weather observation
City – Name of the city
Temperature_C – Temperature in Celsius
Humidity_Percent – Humidity percentage
Rainfall_mm – Rainfall measurement in millimeters
Wind_Speed_kmh – Wind speed in kilometers per hour
Weather_Condition – Weather condition
