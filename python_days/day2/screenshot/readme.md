# 🌦️ Weather Data Analysis

## 📌 Project Overview

This project focuses on analyzing weather and temperature data
using Python and data analysis techniques.

The dataset contains weather information from different cities
in Somalia, including temperature, humidity, rainfall, wind speed,
and weather conditions.

The main goal of this project is to clean, explore, and analyze
weather data to discover useful patterns and insights.

---

## 🎯 Objectives

- Clean and prepare weather data
- Identify missing values
- Explore temperature data
- Analyze humidity and rainfall
- Analyze wind speed
- Compare weather conditions between cities
- Practice Python data analysis techniques
- Generate useful insights from the dataset

---

## 🗂️ Dataset Features

The dataset contains the following columns:

| Column | Description |
|---|---|
| `Weather_Date` | Date of the weather record |
| `City` | City where the data was recorded |
| `Temperature_C` | Temperature in Celsius |
| `Humidity_Percent` | Humidity percentage |
| `Rainfall_mm` | Rainfall in millimeters |
| `Wind_Speed_kmh` | Wind speed in km/h |
| `Weather_Condition` | Weather condition |
| `Source` | Data source |
